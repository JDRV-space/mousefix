# Security Policy

## Supported Versions

MouseFix has no tagged releases. Security fixes are maintained on the current
default branch until a release policy is published.

## Reporting A Vulnerability

Use GitHub's private vulnerability-reporting form for this repository. Do not
open a public issue for an undisclosed vulnerability.

Include the affected commit, macOS version, mouse firmware and connection mode,
reproduction steps, expected impact, and any known workaround. Reports involving
Accessibility or Input Monitoring access, keyboard-event handling, synthetic
input, private macOS interfaces, or HID++ output are especially useful.

Coordinate public disclosure with the maintainer after a fix or mitigation is
available.
